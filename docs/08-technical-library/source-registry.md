# Source Registry

| Field | Value |
|---|---|
| Doc ID | HAK-DOC-SOURCES |
| Status | Research in progress |

Central registry of every external source cited by HAKUREN documentation. Cite only by `HAK-SRC-nnn`. `Verified` means the URL was fetched and the cited section was actually read on the access date; `Partially verified` means only part of the claim support was confirmed; `UNV` means unverified and it must never be the sole basis of an important engineering claim. Categories: official-regulatory, scientific-publication, academic-textbook, national-laboratory, engineering-standard, vendor-publication, educational-reference, secondary-commentary. Marketing material is never independent validation.
