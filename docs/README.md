**HAKUREN — Nuclear Energy & Reactor Engineering Explorer.** *Understand the Atom. Explore the Energy.*

This directory holds the authoritative Phase 0 engineering, scientific, 3D, simulation, software architecture, data contract, quality assurance, traceability, and audit documentation for HAKUREN. Phase 0 is documentation-first: no production frontend, 3D scene, or operational simulator code is implemented here. All specifications follow the TIANEDGE Phase 0 baseline, enforce strict scientific claim classification and source attribution, and maintain civilian nuclear educational boundaries.
